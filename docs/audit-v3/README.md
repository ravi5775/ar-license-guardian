## Usage

1. Start with MASTER_ENTERPRISE_AUDIT_PROMPT.md.
2. Run each numbered prompt in a repository-aware coding environment.
3. Save each output to a markdown file under /docs/audit/<domain>/ with evidence links.
4. Consolidate the final results into the executive report once all prompts are complete.
